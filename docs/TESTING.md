# 首版測試與交付驗收

本文件保存首版的測試入口、覆蓋範圍與既有驗證證據，並說明完整交付仍欠缺的驗收。功能開發已完成實作，但自動測試、隔離原生驗證及真實平台／帳號驗收必須分開判讀；模擬結果不能證明外部服務或完整桌面已驗收。

功能與交付條件見 [SPEC.md](../SPEC.md)，未完成項目的唯一 TODO 清單為 [PLAN.md](PLAN.md)。本文件的「通過」與數量描述沿用下列既有驗證紀錄，不表示本次文件整理重新執行程式測試。

## 檢查入口與執行邊界

- Windows PowerShell 7 執行 `./scripts/check.ps1`；Linux 執行 `bash scripts/check-linux.sh`。只測明確 Go 套件，不用 `go test ./...` 遍歷 node_modules。
- 流程包含 Go 測試／vet／gofmt、前端與生成綁定 Prettier、ESLint、Node vue-tsc、Vitest、Vite 建置、根工具格式／lint 與 Node 工具測試。若沒有 frontend dist，先建前端解除嵌入依賴。
- 安裝／腳本用固定 Bun 1.4.2，Vue 型別與法律／發布用 Node。所有外部 fixture 使用核可暫存目錄，Windows 為 `%LOCALAPPDATA%/Temp/opencode`；不讀真權杖或更動使用者參考原碼。
- HTTP／TCP／可信本機 TLS／假金鑰庫／jsdom 驗證可重現邏輯，不等於真實 Control D、OS 金鑰庫、CDN 效能或 Linux GTK。
- 使用本機 Go 工具鏈並設定 `GOTOOLCHAIN=local`。race 需要 C 編譯器；缺少工具時回報，不自行安裝或升級。

### 僅修改文件

以本地工具檢查 Markdown 格式，另核對 UTF-8 無 BOM、CRLF／法律原文 LF、內部連結、規格一致性與 `git diff --check`。涉及授權來源說明時，另驗法律原文不變及授權工具測試；不因文字整理重新產生綁定、授權資料或發佈產物，未執行的程式測試不得記為重測通過。

```powershell
node scripts/frontend.mjs tool prettier --check --end-of-line crlf "*.md" "docs/**/*.md" "third_party/README.md"
git diff --check
```

## 既有自動測試覆蓋

### DNS、測速與設定

- 雙 DoH 並行、兩來源歸屬／失敗／差異、CIDR／TTL、完整 CNAME 鏈與分類；拒絕私人／特殊 IP、錯 owner 或循環，不因證據年齡拒絕。證據取得 24 小時後、TTL 為零或一年後查驗，仍依實際內容判定。
- 資格後實查雙 DNS、等待下載槽後才重查、末段依 TTL 刷新並保存實取證據；來源失敗／分類或身分變化仍未完成，零 TTL 與網段時間經過不阻擋，IP 輪替及 mixed 政策保留。取消、作業期限、候選／額度不足分開說明，失敗仍記 bytes；同作業來源經過時間不重跑量測或重計流量。
- 到刷新時間的官方快取會重新取得 CIDR，刷新失敗可沿用合法內容；摘要損毀、取消與無合法來源仍拒絕。共享參考不看年齡，仍核策略、私有來源／摘要、網路及官方範圍。
- Host／SNI、固定 IP、未信任憑證、跨域／私人目標／重新導向、讀取期限與取消；共用預算並行安全，0 上限仍計 bytes、可取消，已存非零上限不放寬。
- 官方池 8,192 個 /24 的去重與邊界、近端 64／16／三次三秒與完整 48／16、共享初掃；四個 Fork 跨域 Prepare 共用全作業資格上限，複測亦占資格槽，兩個下載 Fork 仍串行。前段資格失敗仍取後續十個合格候選，失敗不占名額。
- Twitch 首頁／JS 取資源與備援、GitHub 每輪新簽章、X 指定 PNG 完整路徑與查詢參數及 698,569 bytes 三輪短檔；短檔不需 64 KiB，流量含探索完整記帳，X 不依賴 GitHub。固定下載順序、非空 2xx 成功、3xx／空本文失敗且不跟轉址、截斷不成功，完整請求耗時另記。中途資源失敗測試先確認首輪兩個真實下載 GET，再令第二輪探索失敗，驗清分退延遲與取消不誤完成。
- 可信本機 TLS 驗 12 域各自 Host／SNI，含 jtvnw.twitchcdn.net；405 僅證明連線、只有三域下載／其餘九域零自身 Mbps，系統基準保精確 IP；機房只取自身回應，不從 k.twitchcdn.net 借其他 Twitch 域的 POP，無法辨識為未知。
- 參考 v0.8.3 原 rank／evaluate 八個 AST 固定重播，含失敗零值、同順暢不切、沒有額外 20% 門檻、延遲嚴格超過 10 ms；不執行參考主程式或修改 hosts。
- 共享雙來源／十二次可信本機下載、不同尾碼重用、來源分數與目標未量下載分開；相反改善／不完整基準／預算不足／私有證據不符拒絕，不造 IPv6。
- 基準服務選擇展開 2／6／4 域、X 不補 GitHub、shared 只補兩個下載來源，同服務連線結果不干擾來源選擇；空清單／無 token 每次新測 12 域且零寫入、基準不可套用、12 域自訂檔優先、一般無檔預設自身延遲、IPv6 選用及可用才測。
- 必要來源先完成、其餘管理域與基準交錯；有限額度先到管理域，0／2／4／6／12 基準不干擾管理游標。相同網域安全重用有獨立結果 ID 與來源、bytes 不重計，獨立現用規則及自訂檔不被省略，開始前估算不假定去重。
- preset 相容讀取保 near/full／已存額度，正規化擴充、修訂與授權；省略設定 Patch 不誤清 forceWrite，變更停自動清 grants，持久故障不生效。

### 同步、故障與自動授權

- Profile→folders→rules 次序、根目錄不加 `/0`、單夾讀取／跨夾預覽、讀錯停止、普通夾只送 name、移動及寫前動作資料夾檢查；跨夾彙整允許相同 hostname，不以去重或擇一限制拒絕。
- 不可變更預覽、設定／帳號／網路／結果失效、原值摘要、快照／journal、衝突與部分成功；取消零寫入，寫後持久化故障、逾時回讀、重啟不盲重送、復原後值變動保現況。
- download／connection 最後自身 Host／SNI 的精確目標 TLS；失敗或驗完網路改變零寫入，結果時間經過仍在實際驗證後寫入。IPv4／IPv6 各自重驗才寫，測試導可信本機 TLS，不連真實候選。
- forceWrite 關閉維持無改善不寫；開啟有改善仍最佳 IP，完整無改善用雙來源原始 CNAME 優先／原始 IP 次之，保既有 IPv6／comment，不借雲端覆寫或掃描候選。
- do=0／1／3 缺少不適用 via_v6 可安全解析，do=2 缺值仍擋；null／非字串／未知欄位／缺 comment／非 do=2 非空 IPv6 仍擋。HTTP 表單只有 do=2 送 via_v6，代理 HND 可備份、套用及復原，註解與摘要保留；未完成強制預覽用短原因，詳情仍留結果，不暗示可手動繞過。
- 原始 DNS 缺漏／重複／錯誤／來源分歧／鏈／私人或非官方 IP 反例；預覽與整批涵蓋檢查、原 Host／SNI／精確 IP 的 TLS／HEAD，不轉服務尾碼或讀自訂檔；零 TTL 不是反例。
- IPv4 與 CNAME 各連續兩次手動提交，第二次同值仍送；最後 IP／後續鏈變更、TLS 失敗與新增涵蓋規則零寫入。DNS 證據與預覽時間經過仍可寫；已保存且策略相符的測速結果、套用及復原預覽在快取清理後仍可完成模擬套用／復原，實際原值衝突仍阻擋。
- 同值成功／拒絕／逾時／回讀失敗／接受證據保存前後故障／journal 缺欄位，須 writeAccepted 與一致回讀才 verified；否則 unconfirmed 或待核對，不重送、不給成功復原。
- CNAME PUT、200 success true／false／缺欄位、401／403／429，每次寫請求不重試；錯誤遮敏 operation／HTTP／廠商碼／request ID，不保存全文。
- 定期／喚醒／網路穩定等待、完整覆寫／移動／共享授權與冷卻；強制只略冷卻，testOnly 零寫入。前置標記／游標／冷卻保存失敗持久暫停，過時完成不解新故障。
- 執行紀錄單筆／全清的 Go 端保護、已刪／保留計數、事件與重開持久化；保護活動槽、未決項目與未知狀態，索引不能遮蔽待核對作業。保存故障不改列表／原檔，未知版本、欄位、空資料與無效 ID 索引拒啟動且保檔；刪除不改結果／錯誤／設定／origin／checkpoint，不呼叫遠端寫入。原始 journal 保持逐位元組相同，仍可重建冷卻與完成模擬復原；Bridge 拒刪沿統一錯誤紀錄回傳。

## 原生隔離驗證要求

- `--smoke-test` 只能使用既有、完全空白、絕對路徑且非符號連結的目錄。
- 使用假金鑰庫、固定網路與隔離單一實例，不碰 OS 登入設定、外部測速或真實 Control D。
- 核對報告的 version、uiReady、trayAvailable、closeRestored、errorRecorded，並確認 automaticEnabled／credentialsSaved 為 false。
- 持續監測須至少四次、約十五秒，核對 trayChecks／trayMonitoringPassed；快速啟動成功不能代替這項驗證。
